# TechTree - How To Guide

Complete guide for maintaining and updating the IIIT-Delhi TechTree website
(`http://techtree.iiitd.edu.in`).

## Quick Start

```bash
# Update all website data from CSV (the only command you usually need)
python3 update.py

# Start the Flask dev server to preview locally
python3 app.py
# Open http://127.0.0.1:5000 (Course Directory)
# Open http://127.0.0.1:5000/techtree (Graph Viewer)
```

## Prerequisites

- Python 3.6+
- pip packages: `flask`, `pandas`, `numpy`, `gunicorn`
- Node.js (optional, for syntax checking bundle.js)

Install dependencies:

```bash
pip install -r requirements.txt
pip install numpy
```

Note: `requirements.txt` lists older versions for Heroku deployment. For local
development, recent versions work fine. The key packages are:

| Package  | Purpose |
|----------|---------|
| flask    | Web server (serves pages and static files) |
| pandas   | CSV reading and validation |
| numpy    | Force-directed layout fallback (for new nodes without positions) |
| gunicorn | Production WSGI server (Heroku) |

## Architecture

```
Courses.csv                 <-- SOURCE OF TRUTH (edit this)
    |
    v
update.py                   <-- Run this to regenerate all JSON
    |
    +---> static/Courses.json       (Course Directory table data)
    +---> static/graph.json         (Basic graph, reference only)
    +---> static/graph_data.json    (Full graph with positions, loaded via AJAX)
    |
    v
app.py                      <-- Flask server (serves everything)
    |
    +---> / (Course Directory)    uses Courses.json
    +---> /techtree (Graph)       bundle.js loads graph_data.json via fetch()
```

## Updating Course Data

### Step 1: Edit the CSV

Edit `static/Courses.csv`. Required columns:

| Column | Description | Example |
|--------|-------------|---------|
| Serial Number | Auto-incrementing ID | 1, 2, 3 |
| Course Name | Full course name | Foundations of Biology |
| Course Code | Department + number, slash-separated for cross-listings | BIO101 |
| Course Acronym | Short name | FOB |
| Prerequisites | Comma-separated course codes, "or" for alternatives | CSE101 or CSE102, MTH201 |
| Semester | Monsoon / Winter / Summer | Winter |
| Professor | Instructor name(s) | Ganesh Bagler |
| Credits | Credit hours | 4 |
| Cluster | Department cluster for filtering | BIO |
| OptionalDept | Optional department tag | None |
| Preferable_Prerequisites | Recommended but not required | CSE201 |
| Antirequisites | Mutually exclusive courses | BIO102 |
| embed_link | Google Sheets iframe for course description | \<iframe src="..." \>\</iframe\> |

### Prerequisite Format Rules

- **No prerequisites**: `None`
- **Single prerequisite**: `CSE101`
- **Multiple prerequisites** (all required): `CSE101, CSE102`
- **Alternative prerequisites** (any one suffices): `CSE101 or CSE102`
- **Mixed**: `CSE101, CSE102 or CSE103` means CSE101 is required AND either CSE102 or CSE103

Commit and push (or deploy via Heroku):

## Adding a New Course

1. Add a row to `static/Courses.csv` with the next Serial Number
2. Set the Prerequisites to reference existing course codes
3. Run `python3 update.py`
4. The new node will get an auto-generated position via force-directed layout

### Positioning New Nodes

- `update.py` reads existing node positions from `static/networks.json`
- Known nodes keep their positions exactly
- New nodes (not in networks.json) get positions from a built-in force-directed
  layout algorithm
- To get precise positions, open the graph in Cytoscape Desktop, arrange nodes,
  export as JSON, and save as `static/networks.json`

## update.py Command Reference

```bash
# Full update (default CSV path)
python3 update.py

# Use a different CSV file
python3 update.py --csv /path/to/other/Courses.csv

# Validate CSV only (no JSON generation)
python3 update.py --validate-only

# Show help
python3 update.py --help
```

## CSV Validation Rules

The validator checks:

- All required columns exist (Serial Number, Course Name, Course Code, etc.)
- Course codes are at least 3 characters
- Course code components (split on `/`) are at least 3 characters each

Validation errors stop JSON generation. Warnings are non-fatal.

## How the Graph Viewer Works

The graph viewer (`/techtree`) uses a webpack-bundled Cytoscape.js application:

1. `bundle.js` loads in the browser
2. On startup, it fetches `/static/graph_data.json` via AJAX
3. The JSON contains:
   - **Nodes**: Each course with metadata (code, name, professor, semester, prerequisites)
   - **Edges**: Prerequisite relationships with types:
     - `cc` - single prerequisite (solid line)
     - `ORP1` - first alternative prerequisite (dotted green line)
     - `ORP2` - subsequent alternative prerequisites (dotted blue line)
   - **Positions**: x/y coordinates for each node
4. Cytoscape.js renders the interactive graph

### Node Data Fields

| Field | Description |
|-------|-------------|
| `id` | Numeric ID (matches row number in CSV) |
| `CourseCode` | e.g., "BIO101" |
| `name` | Full course name |
| `NodeType` | Department prefix (BIO, CSE, ECE, MTH, etc.) |
| `Prof` | Professor name |
| `Semester` | Monsoon / Winter / Summer |
| `credits` | Credit hours as string |
| `Prerequisites` | Cleaned prerequisite text |
| `Preferable_Prerequisites` | Cleaned preferable prereq text |
| `Antirequisites` | Cleaned antirequisite text |

## Troubleshooting

### "Missing required column" error

Check that your CSV has all required columns with exact names (case-sensitive).
Run `head -1 static/Courses.csv` to see the header row.

### New courses appear at origin (0,0) in the graph

This happens when `networks.json` doesn't have positions for new node IDs.
Fix: open the graph in Cytoscape Desktop, position the new nodes, and re-export
to `static/networks.json`. Then run `python3 update.py`.

### Graph not loading in browser

1. Open browser DevTools (F12) -> Console tab
2. Check for JavaScript errors
3. Verify `/static/graph_data.json` loads (Network tab)
4. If 404, re-run `python3 update.py`

### Bundle.js syntax error

The bundle.js was hand-edited to replace inline graph data with an AJAX fetch.
If syntax errors appear:

```bash
# Check syntax
node -e "new Function(require('fs').readFileSync('static/techtree/bundle.js','utf8'))"

# If broken, restore from backup and re-apply the changes
cp static/techtree/bundle.js.backup static/techtree/bundle.js
```

The two modifications to bundle.js are:
1. Line ~20140: Replaced `H = {{ ... }}` (2172-line inline graph) with `var Q;`
2. Line ~20651: Replaced `k(g(Se), be)` with a `fetch()` call that loads
   `graph_data.json`, sets the global `Q` variable, then calls `k(g(Se), be)`

### Flask won't start

```bash
# Check if port 5000 is in use
lsof -i :5000

# Use a different port
PORT=8080 python3 app.py
```

### CSV has embedded newlines or special characters

The CSV parser handles this, but if you see issues:

```bash
# Check for problematic characters
python3 -c "
import pandas as pd
data = pd.read_csv('static/Courses.csv')
for i, row in data.iterrows():
    for col in data.columns:
        val = str(row[col])
        if '\n' in val or '\t' in val or '\r' in val:
            print(f'Row {i}, {col}: has control chars')
"
```
