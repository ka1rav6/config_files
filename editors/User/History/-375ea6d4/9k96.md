# Hyprland Keyboard Shortcuts

Modifier: `Super` is the Windows/Meta key.

## Session and Windows

| Shortcut | Action |
|---|---|
| `Super + Enter` | Open Ghostty terminal |
| `Super + Q` | Close the focused window |
| `Super + M` | Exit Hyprland |
| `Super + L` | Lock the screen with Hyprlock |
| `Super + F` | Toggle fullscreen |
| `Super + Shift + Space` | Toggle floating mode |
| `Super + Shift + C` | Center the focused window |
| `Alt + Tab` | Cycle to the next window |
| `Super + Super` | Open the application drawer when Super is released |

## Focus and Moving Windows

| Shortcut | Action |
|---|---|
| `Super + Left` | Focus the window to the left |
| `Super + Down` | Focus the window below |
| `Super + Up` | Focus the window above |
| `Super + Right` | Focus the window to the right |
| `Super + H` | Focus the previous workspace |
| `Super + L` | Focus the next workspace |
| `Super + Shift + H` | Move the focused window left |
| `Super + Shift + J` | Move the focused window down |
| `Super + Shift + K` | Move the focused window up |
| `Super + Shift + L` | Move the focused window right |
| `Super + mouse left-drag` | Move a floating window |
| `Super + mouse right-drag` | Resize a floating window |
| `Super + mouse wheel down` | Focus the next existing workspace |
| `Super + mouse wheel up` | Focus the previous existing workspace |

## Resizing

Hold the shortcut to resize continuously.

| Shortcut | Action |
|---|---|
| `Super + Ctrl + H` | Shrink horizontally from the right |
| `Super + Ctrl + J` | Grow vertically downward |
| `Super + Ctrl + K` | Shrink vertically upward |
| `Super + Ctrl + L` | Grow horizontally to the right |
| `Super + -` | Shrink horizontally |
| `Super + =` | Grow horizontally |
| `Super + Shift + -` | Shrink vertically |
| `Super + Shift + =` | Grow vertically |

## Numbered Workspaces

| Shortcut | Action |
|---|---|
| `Super + 1` through `Super + 9` | Switch to workspace 1 through 9 |
| `Super + 0` | Switch to workspace 10 |
| `Super + Shift + 1` through `Super + Shift + 9` | Move the focused window to workspace 1 through 9 |
| `Super + Shift + 0` | Move the focused window to workspace 10 |
| `Super + Tab` | Return to the last workspace |

## Named Workspaces

These shortcuts switch to a named workspace and launch its application if it is empty.
Press the same shortcut again to return to the previous workspace.

| Shortcut | Workspace | Application |
|---|---|---|
| `Super + Shift + Enter` | `tmux` | Ghostty running tmux |
| `Super + Shift + N` | `nvim` | Neovim in Ghostty |
| `Super + Shift + T` | `top` | btop in Ghostty |
| `Super + Shift + G` | `chrome` | Google Chrome |
| `Super + Shift + R` | `brave` | Brave Browser |
| `Super + Shift + D` | `debug` | Development/debug workspace |
| `Super + D` | `desktop` special workspace | Scratchpad-style desktop workspace |

## Applications and Utilities

| Shortcut | Action |
|---|---|
| `Super + S` | Open the application drawer |
| `Super + E` | Open Nautilus |
| `Super + C` | Open Google Chrome |
| `Super + V` | Open VS Code |
| `Super + Shift + A` | Minimize the focused window |

## Screenshots

| Shortcut | Action |
|---|---|
| `Print` | Select an area and copy it to the clipboard |
| `Super + Print` | Select an area and save it to `~/Pictures/Screenshots` |
| `Super + Shift + Print` | Copy the full screen to the clipboard |

## Hardware and Media

These work while the screen is locked where supported.

| Key | Action |
|---|---|
| `Brightness Down` | Decrease brightness by 10% |
| `Brightness Up` | Increase brightness by 10% |
| `Volume Down` | Decrease volume by 5% |
| `Volume Up` | Increase volume by 5% |
| `Mute` | Toggle speaker mute |
| `Microphone Mute` | Toggle microphone mute |
| `Play/Pause` | Toggle media playback |
| `Next Track` | Next media track |
| `Previous Track` | Previous media track |

## Touchpad Gesture

- Three-finger horizontal swipe: switch workspaces.
